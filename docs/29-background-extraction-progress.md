# 提取进度、后台任务与完成提醒

## 用户操作

启动提取后，可返回主页、查询报价或关闭网页。任务由仍在运行的服务器执行；重新登录可在顶部查看当前任务。完成后顶部显示文件名、结果条数及“查看结果”，只有点击后才进入对应批次校对，不自动跳转、提交或入库。完成提醒可手动关闭，刷新不会重复出现。提醒在本浏览器按账号保存；换浏览器仍可从历史记录查看已完成批次。

## 真实进度

后台记录读取文件、本机解析、AI识别、整理、补齐港口、保存结果等阶段；AI分段显示实际完成分段/当前总分段数，自动拆段时总量可能调整。不猜测百分比和剩余时间。耗时由服务器任务起止时间计算。

## 实现与边界

- 数据库迁移011增加progress_json，进度写入验证运行令牌，防止旧执行覆盖新任务。
- GET /api/uploads/tasks返回有权限的最近任务及所有优先排列的进行中任务（最多100条），删除记录不再显示。
- 页面顶部监控独立轮询，离开当前批次后不再由旧轮询改变页面或覆盖新批次状态。
- 刷新或重新登录通过本浏览器保存的任务ID恢复完成提醒。提取结果仍保存在服务器数据库。
- 无需系统通知权限；网页关闭期间不会弹系统通知，重新打开后显示页面提醒。
- 页面断网显示重连提示，恢复后刷新进度；服务器必须保持运行。提取失败显示具体原因及结果入口，不宣称成功。

## 验证

275项后端测试通过，覆盖权限隔离、真实AI分段进度（模拟服务响应）、过期运行令牌、任务结束及删除后状态。真实后台浏览器验收使用虚构Excel及慢速本机解析：离开主页不跳转、刷新后恢复任务、完成提醒、关闭提醒后不重复、点击结果到正确校对批次均通过。前端构建及截图检查通过，无真实报价外发。

仅本地修改，云端及之前离线更新包未改动。
