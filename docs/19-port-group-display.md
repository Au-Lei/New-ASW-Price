# 本地任务四：同港口报价分组展示

## 行为

- 查询页面按起运港、目的港、航线与国家/港口名称快照分组，同组国家英文名、国家中文名、英文港口名、中文港口名仅显示一次（纵向合并）。
- 各船公司、价格来源、协议、运输方案、箱价及有效期仍独占一行，报价条数保持不变。
- 查询简单导出、全量模板导出及详细导出都合并对应B:E单元格，仅组首保留标签；其他列完整保留。
- 保留原模板布局、航线合并和冻结窗格。四列固定与分组兼容。
- 不同起运港、不同目的港ID或不同航线/名称快照不混合。缺少目的港身份的行不自动合并。
- 仅改变显示/导出排序与标签合并，不改报价存储、查询API返回字段、审批及历史版本。编辑/审批界面仍逐行显示，供独立校对。
