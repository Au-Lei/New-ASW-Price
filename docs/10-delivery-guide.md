# 第一版本地试用交付说明

版本1.0.0；2026-10-25。适用不超过10个账号的小团队。单台主机运行FastAPI、SQLite及一个提取线程，浏览器使用；不应启动多个workers，不将数据库放到共享盘。

## 日常使用

1. 启动：在项目目录执行 `bash scripts/start.sh`。当前访问地址以启动终端显示为准；本机网络变化后，需同时修改 `.env` 的 `ASW_HOST` 与 `ASW_ALLOWED_HOSTS`。只在本机用时均设为127.0.0.1。
2. 首次管理员凭据只在主机 `data/admin-initial.txt`，用户自行首次登录改密。管理员创建员工账号，员工首次登录自行改密。不能审批的员工只管理自己的草稿与批次。
3. 基础资料先维护真实船公司、报价供应商及对应协议／报价系列，确认港口名称与别名。
4. 价格查询：选起运港、目的港、船公司、箱型箱量和ETD；未填ETD使用当天，选“全部有效期”才包含未来与过期报价。金额为海运费小计，须另核对费用、限制与实际舱位。
5. 导出：先查询再导出全部结果；不受页码限制。默认青岛至全部目的港、参考日适用报价。内部成本报表保留供应商、协议、费用及版本信息，不作为客户售价表。
6. 更新报价：人工录入，或上传固定模板Excel本机解析；其他表格／PDF／图片只有逐文件确认虚构或脱敏样本后才允许发送DeepSeek。真实报价暂不允许外发，不可将其标为样本来绕过限制。
7. AI结果先对照原件，选行生成草稿，补齐必填字段；缺有效期可保存但不能审批发布。起运港、适用条件和零运费须人工确认。
8. 差异对比：检查新增、修改、无变化和冲突；提交后内容锁定。管理员可审批自己的批次。驳回需理由，撤回或驳回后修改并重新对比提交；重复审批不会重复入库。
9. 改价时从原报价创建修订，保留原件、原始提取和历史版本。新目的港、来源、服务或不重叠有效期应按系统规则并存，不因文件未列出而删除旧报价。
10. 停止：启动终端Ctrl+C；再次运行启动脚本数据保留。

## 安装与配置

交付包 `deliverables/ASW-v1.0.0.zip` 包含源代码、锁定依赖、构建后的前端、测试及说明，附SHA256文件和包内逐文件清单。不含真实资料、账号库、日志、密钥、Python虚拟环境或node_modules。

新主机安装Python环境管理工具uv、Node.js 22.12+或24、npm，解压后进入目录执行：

```bash
bash scripts/setup.sh
bash scripts/start.sh
```

首次安装需从软件包仓库下载依赖；`.env.example`默认仅本机访问、AI关闭。依赖版本见 `backend/requirements.txt` 和 `frontend/package-lock.json`。系统暂按macOS／Linux脚本交付，Windows尚未验证。

需要AI时主机管理员运行 `.venv/bin/python scripts/configure_ai.py` 隐藏输入密钥，再在 `.env` 设置 `ASW_AI_ENABLED=true` 并重启。密钥只在 `.env.ai`，禁止发到聊天、写前端或加入交付包。发送范围仍限制虚构或脱敏样本；更改业务资料外发范围须另行授权和验收。

## 备份、恢复与升级

管理员从“账号与备份”创建并下载完整ZIP，或主机运行：

```bash
.venv/bin/python scripts/manage.py backup
.venv/bin/python scripts/manage.py restore /绝对路径/backup-文件名.zip /绝对路径/尚不存在的新数据目录
```

备份含数据库、账号哈希、原件、AI原始响应、编辑、审批和历史，属于内部成本资料。建议每天使用后以及批量更新或升级前备份，将下载包另存至公司受控备份位置；主机同盘副本不能防止整机磁盘故障。工具不会自动上传到云端。

恢复不覆盖已有目录，会校验完整性与原件关系并移除旧登录会话。先停止服务，保留现有数据；恢复到新目录后在 `.env` 设置 `ASW_DATA_DIR` 指向新目录再启动。原账号密码仍有效，但须重新登录；AI密钥和HTTPS证书须在主机单独配置，不在业务备份中。

备份需与数据库结构版本匹配：当前结构7。旧版备份先配套对应程序恢复；不要把旧结构快照直接当作当前ZIP导入。升级前保留原程序、依赖锁及完整备份；不在现用数据库上手动降级。正式数据的升级前快照仍位于 `data/backups`。

## 常见问题

- 无法打开：检查启动终端是否运行、内网IP是否变化、浏览器是否使用实际地址。其他电脑必须与主机网络互通；请由公司IT检查防火墙或客户端隔离，不直接共享数据库。
- 首次登录后403：完成临时密码修改。401：重新登录或联系管理员确认账号启用状态。
- 提交失败：逐行补齐校验提示；核对是否有重叠有效期、未确认条件、旧预览或并发修改。刷新差异后重新提交。
- AI不能用：查看页面是否启用、密钥是否配置、逐文件样本确认是否保存。401／余额不足／限流／超时均保留原件；处理后手动重试，或改走人工录入。
- 没有查询结果：确认已审批、ETD适用、报价未停用及筛选条件；草稿不出现在正式查询和导出中。
- 报错：记录页面请求编号，主机查看 `logs/app.log`。不要将含真实报价或密钥的文件发到公开渠道。

## 试用边界

软件的本机HTTP、指定内网接口、账号权限、恢复和业务流程已验收；尚未由公司第二台实体设备完成现场连通性确认，不能等同于跨设备验收。当前为HTTP试用，正式公司网络部署建议由IT配置受信任HTTPS证书，之后另测实际登录和文件传输。

AI通过虚构样本实测，不等于复杂真实报价的准确率保证。正式业务使用前应由航线人员对照允许范围内的脱敏样本核验；本系统不承诺舱位或运价最终可订。大数据量、长期压力和Windows安装不在本轮验证范围内。
