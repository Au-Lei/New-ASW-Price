# 图片提取修复（2026-10-25）

## 原因

本机JPEG任务失败码为 AI_TRUNCATED。原流程整张图片一次输出全部报价，约46KB JSON返回时达到输出长度限制，无法组成完整JSON；系统拒绝保存部分结果，造成提取失败。不是图片扩展名或上传损坏。

## 处理

- 800像素以上图片按高度分段，主行裁切保留少量边界重叠；每段携带缩略全图和列标题，供识别跨行国家、有效期及附加费。
- 提示仅输出当前行范围，每条主证据标注原图行坐标。按主行中心限定段归属。
- 遇到截断仅将失败段再二分，最多3层；总调用数、总时限仍受现有配置限制。不拼接截断JSON，不保存不完整报价。
- 邻接段中证据文本、事实、规范化箱价一致且位置靠近共同边界的行做一对一合并。同一段内重复行保留；不同价格保留；证据位置明显分离的相同报价保留。
- 成功分段仍使用原有缓存、证据及逐文件授权机制，失败保留原件与尝试，最终合并才生成可编辑结果。更改提示版本避免复用旧提取缓存。

## 验证

图片相关29项测试通过，涵盖截断拆分、段归属、边界去重及相同报价保留。使用本机生成的虚构15行长表向已配置DeepSeek发起真实图片联调（4个分段）；发现边界重复后，用原始接口返回值本地回放验证最终合并恰好15行，逐项20GP价格匹配。未发送用户本次真实报价图片，未自动重试真实资料，未发布测试报价。测试脚本 scripts/accept_image_bands.py 只生成并发送虚构图片。
