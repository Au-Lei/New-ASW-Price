📖 使用说明

青岛港国际海运报价管理系统

本系统用于国际海运业务中的报价管理与查询。把各代理、船公司提供的协议价资料（Excel / PDF / 图片）上传后，系统提取结构化报价，经人工校对、审批后更新到标价表；业务人员在查询页按港口、船公司、箱型、开船日快速查到有效报价并导出 Excel。

演示版 v0.5 模拟数据 · 未接后端 主表仅修改/新增 18 列对齐报价模板

1项目是干什么的

国际海运报价来源多、格式杂（代理报价单、船公司协议价，有文件、图片），人工查询和汇总费时且容易出错。本系统解决三件事：

  • 统一入库：把各种格式的报价资料提取成模板规定的 18 列结构化数据。
  • 在线查询：按起运港、目的港、船公司、箱量箱型、开船日（ETD）查有效报价。
  • 安全更新：提取结果可校对修改，审批后只对主表做「修改 / 新增」，不删除已有报价；变更行高亮可查。

2功能有哪些

🔍 价格查询
按起运港、目的港（中/英文）、船公司、箱量箱型、ETD 筛选；结果 18 列展示，前两列冻结，有效期状态徽章提示；一键导出 Excel。
📤 上传资料
支持 PDF / Excel / 图片上传（演示为模拟），显示解析状态，全部解析后可提取报价。
✨ 提取报价
把资料提取为结构化报价，以可编辑表格展示；空格标黄待补充，有效期缺失行单独标记。
✏️ 校对编辑
所有单元格可直接编辑，可新增行、移出本次待提交行；移出不影响主表已有报价。
🔄 差异比对
以「船公司 + 价格来源」为唯一键比对：修改行黄底、变化单元格深黄、新增行绿底；汇总修改/新增数量。
✓ 审批入库 & 导出
审批通过后写入主表（只改不删）；可导出查询结果或变更明细为 Excel。
修改行（黄底） 新增行（绿底） 字段有变化的单元格（深黄）

3完整演示步骤

进入首页：顶部有「📖 使用说明」按钮，可随时回到本页；两个入口卡片进入查询或更新。
价格查询：点「价格查询」→ 在「ETD（开船日）」填一个日期，如 2026-11-05 → 点「查询报价」。观察：鹿特丹、汉堡等有效期覆盖该日的报价显示；德班（有效期从 11-10 起）被过滤；奥克兰（有效期为空）保留并标「有效期缺失」。
组合筛选：目的港填「鹿特丹」、船公司选「MAERSK」、箱型选「40HQ」，点查询，结果收窄。
导出查询结果：点右上「📥 导出 Excel」，得到当前结果的 18 列明细表。
更新报价 · 上传：回首页 →「更新报价」→ 点击上传区，模拟上传 3 个文件，等待状态变为「✓ 已解析」→ 点「✨ 提取报价」。
校对：提取结果表格中直接修改任意单元格（如把某条 20GP 价格改掉）；观察空格黄色待补充；有效期缺失行「校验」列有灰标。可点「＋ 新增一行」或「移出」某行（仅影响本次提交）。
提交审批：点「提交审批 →」。若有有效期缺失行会弹确认，点确定进入差异比对页。
看差异：修改行黄底、变化单元格深黄（鼠标悬停看原值）；新增行绿底；顶部汇总显示修改/新增条数。可勾「只看变更行」，可「导出变更明细」。
审批入库：点「✓ 审批通过并入库」，自动跳回查询页。对比入库前后：总条数只增不减，验证「主表不删除」。
建议演示顺序按 2→9 走一遍，约 3 分钟，可完整体现查询、提取、校对、差异、入库、导出全流程。

4关键业务规则

规则说明
唯一键「船公司 + 价格来源」，用于区分同港口多条报价及差异比对。
ETD 校验查询时输入开船日，只返回 有效期起 ≤ ETD ≤ 有效期止 的报价；与船期（周几）无关。
有效期缺失有效期起/止为空的报价：查询时保留并提示；提交审批时弹确认，不强制阻断。
主表变更审批入库只做「修改」与「新增」，永不删除已有报价。
船期模板「船期」列填周几文字（如 周三 / 周一/周四 / 周班），不参与查询过滤。
导出格式演示版导出扁平 18 列明细（方案 B），列名与报价模板一致。

5当前限制（演示版）

  • 上传与提取为模拟：无真实文件解析，点击上传即模拟生成文件与提取结果。
  • 数据不持久：数据存于浏览器内存，刷新页面即还原为初始演示数据。
  • 导出未还原模板格式：为扁平 18 列明细，未包含模板的大标题、合并单元格、分组空行。正式版建议后端用模板引擎按原模板填值导出。
  • 无权限与审批流：演示版「审批通过」为直接入库，正式版需接入角色权限与审批记录。
  • 图片报价识别：正式版需 OCR + 大模型结构化提取，不同代理格式差异大，需保留人工校对环节（本流程已覆盖）。
  • 唯一键较简单：正式版建议用「港口 + 船公司 + 价格来源 + 有效期」复合键，避免同名来源冲突。

6后续规划建议

  1. 接入后端与文件解析（Excel 直读、PDF 表格抽取、图片 OCR + 结构化）。
  2. 按原模板格式导出（openpyxl / 模板引擎），保留分组与合并单元格。
  3. 增加版本管理与变更审计，每次审批可回溯。
  4. 接入角色权限与审批流，区分录入、校对、审批角色。
  5. 报价数据源对接（船公司/代理 API 或定期导入）。
