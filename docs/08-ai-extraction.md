# 任务八：DeepSeek 报价提取

2026-10-25。用户选择 DeepSeek、`https://api.deepseek.com`、`deepseek-flash`。用户明确限定：只允许虚构或脱敏样本，真实报价暂不外发。用户自行在本机配置密钥；开发过程未将密钥输出到聊天或日志。任务九已先行完成，本阶段只补充任务八，不开始任务十。

## 操作方式

1. 管理员先维护船公司、供应商及对应协议／报价系列；港口使用现有基础资料。AI不创建基础资料，也不按相似名称猜测ID。
2. 更新报价 → 上传原件与提取报价 → 保存本批原件。
3. 固定模板 Excel 优先本机解析。其他 Excel、PDF、扫描 PDF、JPG／PNG 使用 DeepSeek 前，逐文件选择“虚构样本”或“已脱敏样本”，勾选确认发送目的地，再保存确认。只有上传不会发往AI；点击提取后才发送。
4. 提取完成后打开“校对AI结果，选择生成草稿”。查看字段、待确认提示、原文证据与对应页码／单元格，下载原件核对。任务记录中可查看原始模型输出。
5. 选中报价行生成草稿，在草稿页编辑、补齐有效期、确认起运港和适用条件。AI不能代替人工确认零运费。生成草稿操作可重复提交而不重复增加数据。
6. 沿用原有差异对比、提交审批、管理员审批入库流程。提取结果和未审批草稿不进入正式报价查询或导出。

不应将真实报价标记为样本来绕过限制。系统记录文件内容校验值、确认人、确认时间及服务地址；无法自动证明使用者已完成业务脱敏。

## 配置

```bash
.venv/bin/python scripts/configure_ai.py
```

脚本使用隐藏输入，将密钥写入项目根目录 `.env.ai`，权限0600，Git忽略。页面只显示是否配置，不提供读取密钥接口。当前本机已配置并启用。其他新部署默认关闭，需在 `.env` 设置 `ASW_AI_ENABLED=true` 后重启。

- 模型固定 `deepseek-flash`，仅请求官方 `https://api.deepseek.com/chat/completions`；禁止重定向，不读取文档内的链接，不调用工具。
- `ASW_AI_TIMEOUT_SECONDS=90`：单次连接／响应超时（5～180秒）；`ASW_AI_TOTAL_SECONDS=600`：总处理时限（30～900秒，调用结束后再次检查）。
- `ASW_AI_MAX_CALLS=20`：每文件分段上限（1～30），超过上限拒绝，提示拆分，不截断后声称完整成功。
- 非标准 Excel 每20个非空行一段，携带原单元格地址、共享表头／脚注及合并信息；公式不执行，引用公式的证据不接受。
- PDF 每3页一段，发送文字与渲染图，补充首尾页概览；图片使用全图，大图补充重叠裁切。来源页码和范围需合法，视觉内容额外提示人工核对。
- 请求最多40MiB、响应最多8MiB；总报价最多500行。既有文件大小、页数及像素限制继续生效。

服务会接收所选样本的文本及必要页面图像。调用可能消耗用户服务账号额度。失败不自动无限重试，使用者在页面手动重试；同文件、同输入、同提示词版本中已成功分段可复用，减少重复调用。API密钥不纳入业务备份，恢复或迁移主机后须在主机重新配置。

## 数据与校验

结构升级6→7：增加逐文件样本确认、`ai_calls` 调用／原始结果、`ai_imports` 不可变提取预览；草稿及 `source_evidence` 沿用原有结构。

输出使用JSON模式、关闭思考输出，服务端以严格结构校验。未知字段、伪造确认状态、错误页码／范围、输出截断均拒绝。字段需引用证据；无证据的值清空待校对。箱价限制非负两位小数；缺币种不猜USD，缺年份不补年份，40GP/HQ口径不明不拆价，航程区间不猜单一天数。原文缺起运港时显示系统默认青岛但未确认，不能直接发布。

原文是资料而非指令：系统提示明确拒绝文档中的角色冒充、命令、审批要求与链接。模型不能发布、审批、访问其他文件或执行工具。任何提示词措施均不能保证模型完全正确，最终须人工核对原件。

上传、确认、预览、原始模型输出及草稿接口均受真实登录、CSRF和本人／管理员批次权限约束。结果存储使用既有执行令牌防止过期任务覆盖新任务。服务重启恢复处理中任务；调用记录、失败原因及原件保留。401、余额不足、429、超时、网络错误、空内容、无报价、格式错误等返回受控中文提示，不回传供应商错误体或鉴权请求头。
