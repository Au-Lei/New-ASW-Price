# 上传记录删除

仅修改本地版本，云端尚未更新。

- 上传文件列表新增“删除”，确认后移除文件，取消保持原样；删除最后一个文件后禁用提取。
- 历史上传与待审批列表每个批次新增“删除”。待审批删除后不能继续审批；已入库批次仅移除上传记录，正式报价不变。
- 后台采用软删除，原件、报价版本、提交快照与审计记录保留，不直接清除磁盘文件。
- 管理员可删除全部记录；业务员只能删除自己的记录。删除接口仍验证登录与CSRF。
- 正在提取时暂不允许删除；排队任务会取消。已经生成校对报价的单文件请删除整批，避免残留关联草稿。
- 删除后的同一文件可以重新上传；固定模板导入不复用已删除批次的预览。

验证：后端全量262项通过；浏览器验证文件删除、确认取消、历史批次删除和重新上传通过；前端构建通过。
