# 价格来源和备注人工填写规则

- 新提取报价的价格来源留空。AI prompt要求supplier/source_series为空，服务端忽略这两个字段；固定Excel导入也不识别价格来源列。显式人工导入选项、校对页人工填写仍可保存。
- 备注仅允许原文明确标注备注、注意事项或对应Remarks/Notes栏目时提取；特别说明、识别疑问、附加费用、船公司标题等不自动写进备注。
- 校对页不再从AI原始结果或Excel原文恢复自动忽略的价格来源。
- AI提示词版本已更新，避免重新提取复用旧规则缓存。页面脚本版本同步更新。
- 已有人工编辑、历史提取结果和已发布数据不追溯清空。
