# 本地任务五：Excel格式支持

## 排查
原上传入口明确拒绝.xls；读取器只处理OOXML压缩包；原件路径及备份校验也仅接受.xlsx。只修改选择框或调用AI无法解决。

## 实现
- 新增xlrd 2.0.2依赖，读取Excel 97-2003的BIFF8 .xls。输出与现有.xlsx读取器一致的工作表、单元格、日期、合并范围与公式标记。
- 根据文件签名读取实际格式，支持.xls/.xlsx扩展名误写和大小写扩展名。保留原件原始字节、名称和校验值。
- .xsl仅作为误命名Excel的兼容入口；真正的XSL样式表、HTML伪装表格、损坏文件及加密工作簿提示另存为未加密.xlsx。Excel 97之前的BIFF版本暂不支持，明确提示另存。
- 固定模板和POD表继续本机解析；非固定表转换为现有AI输入结构，仍受逐文件样本发送授权约束，不自动对外发送。
- BIFF公式记录标记为公式，清除缓存值，不运行宏/公式。公式价格不作为普通静态价格导入。
- 上传选择框、固定模板导入、原件下载、备份和恢复均支持新增格式；导出继续使用.xlsx。
- 不迁移现有业务数据库，不改云服务器，不上传GitHub。

## 验收
虚构二进制测试文件位于backend/tests/fixtures/legacy-*.xls，由xlwt 1.3.0生成；测试运行仅需xlrd，不依赖Excel或xlwt。
覆盖真实BIFF8静态价、日期、合并单元格、公式拦截、误命名、格式拒绝、上传/提取/草稿/审批入库/查询、原件逐字节下载、备份恢复、固定模板导入及非结构表AI准备。未调用外部AI。
