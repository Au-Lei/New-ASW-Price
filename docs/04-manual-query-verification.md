## 实现范围

- 首页“更新报价”可新增和编辑人工草稿，默认起运港青岛；改选起运港后须重新确认。
- 港口按中英文、代码及已确认别名检索，再在包含国家、码头的候选列表明确选择，不自动合并同名地点。
- 草稿可保存不完整或待修正字段；保存后逐项显示校验结果。原始录入、后续修改、修订号、手工依据及审计记录持久保存。
- 校验港口／来源／航线引用及停用状态、目的港航线关系、服务、币种、日期、至少一种箱价、正整数航程、零价确认、人工依据和适用条件确认。
- 正式价格查询支持起运港、目的港、船公司、ETD、全部有效期、混合箱量、排序和分页。
- 展示来源、三箱型单价、币种、服务、路径、船期、航程、有效期及状态、费用包含范围、适用限制及备注。
- 金额用十进制解析为整数分后计算，输出两位小数。同一报价内计算小计；缺价不当0，不跨来源拼单、不跨币种合计或排名。
- 排序支持目的港、船公司、有效期止、航程天数及升降序；分页支持10／20／50条。首版不提供跨费用条件的价格排名。

## 正式查询与草稿试查边界

任务一Q01仍然成立：`/api/quotes/search`只读正式报价当前版本，排除停用、历史版本和所有草稿。
审批入库属于任务六，任务四不增加直接发布或绕过审批接口。

为了在任务六之前验证人工录入后能查询，单独实现`/api/manual-drafts/search`及标明“草稿试查（未审批）”的界面范围。仅纳入字段校验通过且仍可编辑的人工草稿，逐条显示草稿标识；不完整草稿只保存在编辑页，试查返回排除数量。
两个查询入口复用筛选、有效期、分页、小计逻辑，不混合结果。试查不是正式报价，不属于对Q01的放宽，不支持导出或自动入库。
首次正式数据库仍无已审批报价，因此普通查询为空是正确行为；用户可先在基础资料建立船公司、供应商及协议系列，再录入草稿并试查。

## 字段与输入约定

- 每箱价格为空／null表示缺价；显式0元需对应箱型零价确认。负数、非数字、科学计数、超过两位小数不通过字段校验。
- 单价上限9,999,999,999.99，箱量1～100000整数，金额输入保留字符串避免浏览器浮点转化。
- 当前支持USD、CNY、EUR、GBP、JPY、HKD、SGD、AUD、CAD、CHF、NZD、KRW、AED、INR；其他币种可留草稿待扩充，不伪造支持或换汇。
- 航程为1～99999正整数或空；区间说明保存在备注。
- 日期使用YYYY-MM-DD，校验实际日历日期及起止顺序。ETD留空按Asia/Shanghai当天；两端含当日。
- 状态按参考日互斥计算：未生效、有效、即将到期（0～10天）、已过期。缺有效期只在草稿校验中显示，不作为适用报价试查。
- 当前操作者标明“本机录入”，真实账号与权限留任务九。编辑检查草稿修订号及批次锁定状态，不覆盖旧版或待审批批次。
