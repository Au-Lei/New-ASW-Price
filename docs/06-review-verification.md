# 任务六：报价更新、差异对比与审批

日期：2026-10-25。范围仅任务六；任务七未开始。

## 已实现

- 批次对比：新增、修改、无变化、批内重复；逐字段前后值、完整费用与适用条件、原报价和新报价证据可核对。
- 匹配口径包含起运港、目的港、船公司、报价系列（关联供应商）、服务标识、直达／中转、路径、费用口径、币种、条件。同口径同期自动比较，非重叠新期独立新增；不同口径共存。
- 重叠有效期、目标版本变化、批内矛盾及必填缺失阻止提交。可明确选择目标版本，更正服务或日期后仍检查其他期间重叠，不自动拆分有效期。
- 空白字段默认保留原值，支持逐字段保留、使用本次值、明确清空；必填清空仍不可提交。金额采用Decimal转整数分，缺价不视为零价。
- 批内相同报价合并；不同报价不会跨来源覆盖。未上传的旧行保持原样。取消勾选的行在提交时移到独立可编辑草稿。
- 草稿可保存缺项；提交必须完整有效、无冲突且有实际变化。预览令牌核对批次修订、目标当前版本、引用资料和来源证据；旧预览不能提交。
- 提交冻结快照、锁定编辑；待审批可撤回，驳回须非空理由。重提产生独立快照，已撤回旧提交不可审批。数据库触发器禁止修改或删除提交和审批记录。
- 管理员可自批。审批前在写事务内重新比较，其他批次发布、目标停用或基础资料停用会拒绝旧审批。审批操作编号幂等，复用编号处理其他审批或不同决定报冲突。
- 整个批次的报价、版本、箱型价、证据、审计及审批状态在同一SQLite事务内写入；失败全部回滚。旧版本保持历史，正式查询与导出只取未停用的当前版本。
- 正式查询可创建修订草稿、查看版本历史、填写原因停用。每个新发布版本冻结资料显示名称，后续字典更名不会改写原报价显示；早期测试或外部旧数据无快照时兼容现有字典。
- 审计记录包含实际本机操作员、提交／审批／撤回／拆稿／修订／停用及前后信息。原Excel文件、工作表与单元格来源继续保留。

## 身份边界

当前依旧是仅127.0.0.1本机模式，服务端固定“本机管理员”，没有公开角色切换或信任客户端角色请求头。服务端检查有效操作员、管理员审批／停用、本人批次编辑及撤回权限。专项测试注入服务端业务人员身份验证403，未将前端按钮隐藏当作权限控制。

本阶段不宣称已提供真实多人登录或可部署的用户认证。正式账号、登录会话、完整基础资料权限和局域网配置在任务九完成后统一验收；不应现在开放局域网访问。
