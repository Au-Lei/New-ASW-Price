## 账号与权限

- 服务启动时将原本机操作员迁移为真实管理员，保留`local-admin`身份与历史关系；旧批次未记录归属的统一归该管理员。
- 首次管理员用户名及随机临时密码只写入主机`data/admin-initial.txt`，权限0600，不写入日志、聊天或公开接口。首次登录必须修改密码；成功后临时文件移除并重新登录。其他新建／重置账号也使用单次显示的随机临时密码，首次登录须修改。
- 密码以随机盐scrypt散列存储，参数N=32768、r=8、p=3；新密码12～128位，去除首尾空白后不少于12位。参数参考[OWASP密码存储指南](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
- 登录采用服务端持久会话，浏览器Cookie HttpOnly、SameSite=Strict，默认8小时固定有效期，可配置1～24小时。服务端只保存会话令牌散列；退出、改密码、停用、改角色和重置密码撤销相应会话。恢复备份撤销全部原会话。
- 修改操作检查CSRF令牌与同源请求；登录也拒绝跨站来源。按账号与来源地址限制连续失败，5次失败后15分钟内拒绝重试，并有地址维度限额。失败记录持久化。
- 业务数据、字典、导出、原件、任务、审批及备份接口全部要求登录；只有健康检查、登录状态提示、登录接口及前端静态资源无需登录。公开健康检查不返回业务资料。
- 最多启用10个账号。业务人员可共享正式查询／内部导出、创建和编辑本人草稿、提交及查看本人上传和审批批次；不能审批、停用报价、修改字典、管理账号或备份。管理员可处理全部批次和上述管理操作，允许自批。管理员查看来源原件不受批次归属限制。
- 草稿、导入、上传、提取与批次的归属由后端检查，不能依赖隐藏按钮或客户端角色字段。至少保留一名启用管理员。关键动作记录实际账号，后台提取使用明确的系统审计身份，不回退为浏览器管理员登录。

## 日常操作

1. 使用下方当前地址打开系统；在主机查看初始凭据，首次登录自行修改密码并重新登录。
2. 管理员进入“账号与备份”，创建同事账号，将临时密码交给本人；同事首次登录修改密码。
3. 停用、改角色或重置密码都会撤销该账号既有会话。停用不删除报价和审批历史。
4. 管理员点击“创建完整备份”，成功后下载到独立存储；备份期间请暂停更新报价，查询仍可使用。备份含成本报价、原件和账号散列，按内部资料保管。

## 完整备份与恢复

备份包含一致的SQLite快照、所有数据库引用的原件、SHA256清单及版本信息。采用[SQLite备份API](https://www.sqlite.org/backup.html)，复制原件期间持有写事务排他入口，避免数据库与文件记录错位；不直接复制运行中的主数据库文件。原件缺失、篡改或路径异常时明确失败，不生成“成功”备份。

网页备份仅管理员可创建及下载；磁盘文件权限0600。归档不含`.env`、TLS私钥、初始临时密码文件和日志，这些部署配置应由主机管理员另行保管。会话及登录失败记录在恢复时清除，不恢复旧浏览器的访问权限。

主机命令：

```bash
.venv/bin/python scripts/manage.py backup
.venv/bin/python scripts/manage.py restore /绝对路径/backup-xxx.zip /绝对路径/新的data目录
```

恢复只接受尚不存在的新目录，不覆盖在线库，不删除现有数据。检查归档路径、清单、数据库／原件散列、数据库版本、完整性及外键关系，拒绝额外成员、重复成员、链接与目录穿越。当前恢复支持同结构版本备份，归档展开总量上限10GiB。

恢复后先停止当前服务，再将`.env`的`ASW_DATA_DIR`切换到新目录并启动，使用备份中的账号密码重新登录。保留原目录，验证通过后再处理旧资料。不要让两套服务同时管理同一数据库或队列。

## 局域网配置

当前主机IPv4为`192.168.31.25`，正式实例只监听该地址，访问：

**http://192.168.31.25:8000/**

本机与同网络设备均使用此地址；当前不再监听旧的127.0.0.1地址。`.env`已设置：

```dotenv
ASW_HOST=192.168.31.25
ASW_PORT=8000
ASW_ALLOWED_HOSTS=localhost,127.0.0.1,[::1],192.168.31.25
ASW_SESSION_HOURS=8
ASW_COOKIE_SECURE=false
```

`bash scripts/start.sh`启动，Ctrl+C停止。默认示例配置仍是本机模式。若仅本机使用，改回`ASW_HOST=127.0.0.1`；若内网IP改变，同时更新监听IP和允许主机列表。可用`.venv/bin/python scripts/lan_info.py`只读查看候选地址与说明。

启动脚本不执行`.env`内容作为shell代码，关闭代理请求头信任；不自动修改防火墙、路由器、端口转发或共享数据目录。公司设备需在同一可互通网络，客户端隔离／防火墙限制需由公司网络管理员确认。不能从另一设备使用127.0.0.1访问主机。

当前为HTTP试用，传输不加密。公司正式使用应配置受信任HTTPS证书：设置`ASW_TLS_CERT`和`ASW_TLS_KEY`后启动，脚本自动启用Secure会话Cookie。证书须包含实际访问名称／IP，交由公司IT配置及信任；本轮未安装证书、未验证实际HTTPS部署。

自动审批曾拒绝全网卡长期监听0.0.0.0，原因是范围过宽；已采用只绑定当前内网IPv4的较窄方案并通过启动及访问检查，未绕过拒绝。
