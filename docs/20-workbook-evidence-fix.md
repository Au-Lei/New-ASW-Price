# Excel AI证据摘录导致提取失败的修复

## 排查
云端错误为AI_SOURCE_INVALID：AI证据片段与对应单元格原文不符。本机同名工作簿为非固定表、无公式，存在分组和合并单元格，需走AI解析。
旧代码要求AI的excerpt为整个引用范围原文拼接的连续子串；改写分隔符、添加标签或省略中间列会导致整个提取任务失败。

## 修改

Excel以程序直接读取的真实单元格范围作为证据，不以AI改写的摘录作为事实。摘录格式不一致时逐字段核对并给出校对提示；输出证据使用真实原文，原AI摘录保留在raw与调用记录中。工作表、坐标、处理范围、空范围和公式校验保留。无法在实际范围找到的字段/价格留空。
数字按完整数值匹配，避免把11000中的1000误当已存在报价；千位符和等值小数兼容。
新prompt版本shipping-extract-9-workbook-evidence；增加无箱型表头的斜线报价不得猜箱型、无日期说明的数值不得猜有效期、续行继承港口须引用真实标题来源的规则。

## 验收边界

使用虚构摘录验证分隔符、标签、无关改写不再导致整批失败；捏造船公司不采信，错误价格及空引用范围被拦截，公式及越界校验继续保留。真实工作簿仅在本地读取结构，未发送给外部AI；云端实际AI重试由用户在安装修复后验收。
